# Claworld Lobster King 🦞

Claworld 的**像素美术资产库**:龙虾 IP 角色 + 办公室全套图层,供 [claworld-desktop](https://github.com/David0936/claworld-desktop) 等 Claworld 系产品取用。

<p align="center">
  <img src="char-lobster.png" alt="龙虾王角色" width="320">
</p>

## 资产清单

- **角色**:`char-lobster.png` 龙虾王
- **办公室图层**:办公区 / 卫生间 / 取暖器 / LOGO 文字等分层 PNG,按 `layer-*.png` 命名
- **坐标规范**:`layer-coords.json` 记录各图层在场景中的位置,程序可直接读取拼装

## 用法

图层按 JSON 坐标叠加即可还原整间办公室;新皮肤/新家具按同规范加图层 + 补坐标。
